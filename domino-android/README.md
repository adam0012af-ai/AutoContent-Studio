# Domino Android

لعبة دومينو أندرويد بدون إنترنت، لاعب واحد ضد الكمبيوتر.

## المميزات
- Double-Six كاملة: 28 قطعة
- 7 قطع لكل لاعب
- اللعب على الطرفين
- السحب عند عدم وجود حركة
- خصم كمبيوتر تلقائي
- نهاية مغلقة واحتساب بالنقاط
- واجهة Landscape

## البناء
```bash
gradle assembleDebug
```

الناتج:
`app/build/outputs/apk/debug/app-debug.apk`
